طريقة رفع تحديث كرة القدم V22.2 إلى GitHub Pages
===============================================
1) احتفظ بنسخة احتياطية من ملفات مستودع اللعبة المنفصلة قبل الاستبدال.
2) فك ضغط الحزمة الجديدة على الكمبيوتر، ولا ترفع ZIP بحد ذاته إلى GitHub Pages.
3) ارفع محتويات الحزمة (index.html و app.js و config.js ومجلد runtime كاملاً...) مباشرة إلى جذر مستودع اللعبة المستقلة، أو إلى مجلد النشر المحدد في GitHub Pages.
4) افتح Settings ثم Pages واختر النشر من الفرع والمجلد الصحيحين (غالباً main و /root) إن لم تكن منشورة بالفعل.
5) افتح رابط GitHub Pages للعبة، واستخدم Ctrl+Shift+R إذا استمر المتصفح في عرض ملفات قديمة.
6) افتح لوحة المعلمة، اكتب اسم مدرسة مختلفاً في حقل «اسم المدرسة» ثم «تجربة اللعبة الآن».
7) داخل الملعب يجب أن يظهر الاسم الجديد على اللوحات المضيئة ولوحة النتائج وشريط البث والترحيب؛ ويجب ألا يظهر أي اسم مدرسة ثابت من النسخة السابقة.
8) جرّب تصدير نسختي المعلمة والطالب بعد التعديل على اسم المدرسة، فكل منهما تحوي الاسم نفسه في الإعدادات والمحرك.

ملاحظات:
- المشروع موقع ثابت ولا يعتمد على قاعدة بيانات أو على منصة أبو عبيدة أو على خدمة API خارجية.
- التشغيل دون إنترنت: فك الضغط على ويندوز وشغّل START_GAME_WINDOWS.bat، مع تثبيت PowerShell (مدمج في ويندوز) أو Node.js أو Python كبديل حسب تعليمات README_AR.txt.
- GitHub Pages يحتاج إلى الإنترنت لفتح الموقع أول مرة؛ حزمة ZIP المحلية لا تحتاج إلى الإنترنت.
- لا ترفع ZIP مضغوطاً فقط وتتوقع أن GitHub Pages يفتحه؛ يجب رفع ملفاته بنفس هيكل المجلدات.
- الاسم الافتراضي في إصدار المصدر الجديد «اسم المدرسة»، ويمكن تخصيصه من لوحة المعلمة.
