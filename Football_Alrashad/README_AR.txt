الصف الرابع — العلوم: الحياة الصحية

التشغيل محليا دون إنترنت:
1. فك ضغط الحزمة كاملة باستخدام «استخراج الكل» في ويندوز.
2. افتح index.html في متصفح Edge أو Chrome حديث.
3. اكتب اسم اللاعب أو المجموعة ثم اضغط «ابدأ اللعب».
4. اختر ضربات الجزاء أو المباراة التفاعلية.
لا تحتاج تثبيتا أو حسابا أو خادما أو إنترنت. تعمل داخل المتصفح من ملفات الجهاز مباشرة؛ وليست برنامجا تنفيذيا EXE.

تعديل الأسئلة والبيانات:
اضغط «لوحة المعلمة» أعلى الصفحة. يمكنك تعديل الاسم والمدرسة والمعلمة والمنسقة والصف والأسئلة والإجابات واللوحات والألوان.
تحفظ المسودة في المتصفح على هذا الجهاز. للحفظ الدائم والنقل استخدم «حفظ الإعدادات والأسئلة» أو «تصدير نسخة المعلمة ZIP».
نسخة الطلاب المصدرة تفتح اللعب مباشرة ولا تعرض لوحة التحرير. لا تعتبر حماية سرية للإجابات لأن اللعبة تعمل محليا.

النشر على GitHub Pages:
فك الضغط أولا، وارفع محتويات المجلد بحيث يكون index.html في جذر المستودع، مع runtime وجميع الملفات الأخرى.
لا ترفع ملف ZIP وحده ولا تنقل index.html منفردا.
فعّل Pages من إعدادات المستودع وحدد الفرع والمجلد الجذر. تعمل الحزمة عبر مسار المستودع الفرعي أيضا.
نفس الملفات تعمل محليا دون إنترنت أو عبر استضافة ويب. فتح رابط الموقع لأول مرة يتطلب الإنترنت؛ للتشغيل المضمون بدون إنترنت استخدم الحزمة المستخرجة محليا.

ملاحظات:
الرسوم ثلاثية الأبعاد تحتاج WebGL. إذا تعذر تشغيلها تتيح اللعبة نسخة نصية مبسطة.
لا اتصال بمنصة الألعاب ولا قاعدة بيانات ولا تسجيل دخول ولا طلبات إلى مواقع خارجية.
كل الصور والصوت والمكتبات اللازمة مدمجة محليا. حذفت الصور القديمة غير المستخدمة والنسخ المكررة لتقليل الحجم دون حذف رسوم الملعب الحالية.
ملف QUESTIONS_AR.txt يتضمن الأسئلة ومفتاح الإجابات وتوزيعها على صفحات الملزمة.
للمطور: إذا عدلت ملفات المصدر مباشرة شغّل tools/rebuild.py قبل استخدام زر تصدير ZIP؛ تعديل الأسئلة من لوحة المعلمة لا يحتاج بايثون.
